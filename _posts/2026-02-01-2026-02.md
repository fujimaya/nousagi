# 02/23 Mon

## Macで同一アプリの切り替えショートカット

参考:  
https://dev.classmethod.jp/articles/mac-next-window-shortcut/


`システム設定 > キーボード > キーボードショットカット` から

`キーボード > 次のウインドウを操作対象にする` の項目をダブルクリックして、

USキーボードなら Cmd + `（Tabの上）を入力して、切り替えられるようにした。

この設定は個人的には便利

## Macでcommand/pyを作って実行

ターミナルを開いて

```
touch newfile.command
chmod +x newfile.command
chmod +x newfile.py
```

Pythonを実行する場合も合わせて、実行権限を付与する必要がある


# 02/08 Sun

## MacのVisual Studio Codeで.NET開発

必要なもの
- Visual Studio Code
- .NET SDK
- C# Dev Kit（VSCode の拡張） 
  
参考：  
https://learn.microsoft.com/ja-jp/dotnet/core/tutorials/with-visual-studio-code?pivots=vscode



Create .NET Project を選択して、コンソールアプリを選ぶと、プロジェクトが作られる。

メニューの `Run > Run Without Debugging` を選択すると実行される。


実行しようとしたら .NET9 のランタイムが求められたのでこれも追加インストール  
https://dotnet.microsoft.com/ja-jp/download/dotnet/thank-you/runtime-9.0.12-macos-arm64-installer?cid=getdotnetcore


# 02/07 Sat

## Jenkinsの起動失敗

`sudo systemctl start jenkins`  
やってもエラーが返ってくる。

`sudo -u jenkins /usr/bin/jenkins`  
実行したら、下記のエラーが出ていた。


```
Running with Java 11 from /usr/lib/jvm/java-11-openjdk-amd64, which is older than the minimum required version (Java 17).

Supported Java versions are: [17, 21]

See https://jenkins.io/redirect/java-support/ for more information.
```
Javaが古いみたい。



`sudo apt update`  
`sudo apt install openjdk-17-jdk`  
OpenJDK 17 をインストール

`sudo systemctl start jenkins`  
そのあとは無事に起動した
