## Visual Studio Code からの Copilot 利用
最近の Visual Studio Code には、デフォルトで GitHub Copilot のプラグインが含まれている。

そのため、Copilot のアカウントがあれば、VSCode で AI 支援が受けられる。
ちなみに、Microsoft Copilot と GitHub Copilot は別物なので注意が必要。Microsoft Copilot は Office の資料作成など、一般的なタスクに特化している。
GitHub Copilot はコード生成用。

## Git のユーザー名とパスワード変更

### 現在の設定を確認
```
git config user.name
git config user.email
```

### 新しい設定
```
git config --local user.name "NewUserName"
git config --local user.email "new@example.com"
```

## Jekyll でのブログ運用
GitHub Page + Jekyll でブログを運用してみる。  

Jekyll の実行は、GitHub 標準で使えるものと、Github Actions から使うやり方があるみたいだが、今は標準のものを使っている。

GitHub Page の設定で `Build and deployment` にある Source を `Deploy from a branch` にすることで、md ファイルをアップロードするだけで自動で Jekyll が実行されるみたい。

自動実行したくない場合は、リポジトリ内に .nojekyll を配置するか、もしくは Source が `GitHub Actions` になっている場合は自動では更新されない。Github Actions を使う場合は自分でワークフローの設定が必要になる。

また、Deploy from a branch 設定だと、1時間に10回の Deploy 制限があるみたい。
