# 10/24 Sat
## Jekyll でのブログ運用
GitHub Page + Jekyll でブログを運用してみる。
Jekyll は GitHub 標準のものと Github Actions を使うやり方があるみたいだが、今は標準のものを使っている。

GitHub Page の設定で、`Build and deployment` の項目にある Source を `Deploy from a branch` に設定しておくことで、mdファイルをアップロードすれば自動でJekyll が実行される。

リポジトリ内に .nojekyll がある場合と、Source が `GitHub Actions` になっている場合は、自動では更新されない。Github Actions を使う場合は自分でワークフローの設定が必要。

また、Deploy from a branch 設定だと、1時間に10回の Deploy 制限があるみたい。
