# 01/28 Wed

## Visual Studioで特定のスレッドのデバッグ実行

マルチスレッドのプログラムをデバッグ中、F10でステップ実行を行うと、実行ごとに別のスレッドが実行しているコードにも置き換わってしまうので確認がしづらい。

特定のスレッドのみステップ実行するには、ブレークポイントに入ったあとに、Debug → Windows → Threads を起動する。

実行中のスレッドがリストで表示されるので、目的のスレッド以外を選択して、右クリックして「Freeze」する

# 01/16 Fri

## 複数PDFのマージ

``` Python
import glob
from pypdf import PdfWriter

merger = PdfWriter()

target = "C:/Users/Name/Desktop/pdf2"

for pdf in sorted(glob.glob(target + "/*.pdf")):
    merger.append(pdf)

merger.write("C:/Users/Name/Desktop/output.pdf")
merger.close()
```

`pip install pypdf`でインストールできる。

PythonのPdfWriterが便利だった。  
そこそこページ数が多いPDFも一瞬で終わるぐらい処理が高速。
