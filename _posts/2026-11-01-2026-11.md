# 11/14 Sat
## Ubuntu 26.04 インストール

使っていない Intel Mac mini に Ubuntu をインストールする。  
マシンは Core i5 2.50GHz x4 / Memory 4GB という非常に低スペックなので、Ubuntu 26.04 Desktop だと推奨環境を満たしていない。ただ、ほぼファイルサーバー用途でしか使わないので起動さえできれば何とかなると思う。（たぶん）

インストールに必要な物
- USB メモリー（16GB で十分だった）
- ISO イメージ　<https://ubuntu.com/download/desktop>
- Rufus　<https://rufus.ie/ja/#download>

Rufus を使って USB メモリーに ISO を書き込む。  
Mac mini に USB を指して、Windows キーの Alt キーを押しながら起動。起動ディスクが選択できるので「EFI Boot」を選ぶ。ちなみに、使わなくなった Dell PC にも Ubuntu を導入したが、そちらは起動時に F12 を押すことで、ブートの設定モードが立ち上がった。

USB からブートさせると、OS のインストーラーが立ち上がるので、あとは画面の指示に従って進めて行けば、インストールが完了する。

注意点としては、インストール時に有線LANを接続しておかないと、インストール完了後もインターネットに接続できないという問題が起きた。OS の再インストールする羽目になった。

### 削除したファイルサーバーのデータを復旧

Ubuntu に外付け HDD を繋いでファイルサーバーとして運用していたことがある。その際、間違って削除してしまったデータを PhotoRec を使って復旧させた。

外付け HDD をマウントする。最初にどこに接続されているかを確認する。
```
lsblk -f
```

今回は sdb2 だったので、/mnt/hdd にマウントしてアクセスできるようにする。
```
sudo mkdir -p /mnt/hdd
sudo mount /dev/sdb2 /mnt/hdd
```

復旧用ツールのインストール
```
sudo apt update 
sudo apt install testdisk
```

```
sudo photorec /d /mnt/recovery/Desktop /dev/sdb2
```
/mnt/recovery: 復元先のフォルダ（必ず外付けHDDとは別にする）  
/mnt/hdd: 解析対象の外付けHDD

## 復旧したデータへのアクセス

### ファイルサーバー経由

Samba をインストールして、ネットワーク経由でアクセスする。
インストール方法の詳細は ChatGPT に聞けば詳しく教えてくれる。

共有フォルダーの設定はこんな感じ
```
[HDD]
   path = /mnt/hdd
   browseable = no
   read only = yes
   guest ok = no
   valid users = ubuntu
```

最後の valid users は、`whoami` コマンドで表示される実際の ubuntu ユーザーを指定した。
下記コマンドで、Samba へアクセスする、ubuntu ユーザーのパスワードも設定できる。
```
sudo smbpasswd -a ubuntu
```

UFW の設定で自宅のネットワークからのみアクセスを許可するようにした。これも詳しくは ChatGPT へ。
```
sudo ufw allow from 192.168.1.0/24 to any app Samba
```

#### Windows からのアクセス

Explorer から下記でアクセスできた。
```
\\192.168.xxx.xxx\HDD
```

### USBメモリーへコピー

最初はこちらを USB へのデータコピーを行っていたが、アクセス速度が遅いので効率は悪かった。  
photorec で見つかったファイルが /mnt/recover 以下に書き込まれていたとして、下記コマンドで別のUSBにデータをコピーした。

```
find "/mnt/recover" -type f -iname "*.pdf" -exec cp -iv -t "/run/media/ubuntu/KIOXIA/" -- {} +
```
