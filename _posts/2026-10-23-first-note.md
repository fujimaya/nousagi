記事は **1記事につき1つの `.md` ファイル**で管理します。見た目は共通のテンプレートから自動で作られます。

<!--more-->

## 記事の書き方

`_posts` フォルダに `年-月-日-記事名.md` という名前でファイルを追加します。ファイルの先頭にタイトルなどを書き、その下に本文を書きます。

### 箇条書き

- 思いついたことをメモする
- 学んだことを整理する
- コードや画像を添える

### コードも書けます

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, blog!" << std::endl;
}
```

### 表の表示

| ファイル | 役割 |
|---|---|
| Markdown | 記事の本文 |
| HTML | ページの構成 |
| CSS | 色・文字・余白 |

> 小さな発見も、書き残せば次の自分へのヒントになります。

## 次の記事を追加する

このファイルをコピーし、ファイル名・タイトル・本文を変更してください。公開すると記事一覧に自動で表示されます。
